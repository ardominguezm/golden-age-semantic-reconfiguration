# Publication-derived data

This directory contains compact derived data corresponding to the principal figures and tables reported in the associated manuscript. The files are provided to make numerical results easy to inspect independently of the full Colab workflow.

## Figures

- `figures/figure2_temporal_rewiring.csv` — temporal rewiring trajectories under author-balanced and raw weighting.
- `figures/figure3_null_model_contrast.csv` — N1 and N2 counterfactual percentiles and empirical tail probabilities across node representations.
- `figures/figure4_mechanism_decomposition.csv` — contribution shares from relation births, deaths, and shared-relation reweighting.
- `figures/figure5_diffuseness.csv` — contribution-coverage graph summaries.

Figures 1 and 6 are schematic/contextual figures and therefore do not have independent numerical plot-data files.

## Tables

- `tables/table1_design.csv` — corpus and analytical design summary.
- `tables/table2_robustness.csv` — representation robustness and counterfactual diagnostics.
- `tables/table3_textual_provenance.csv` — selected high-contribution relations and philological provenance.

All values are derived from the versioned analysis code and the analytical specifications described in the manuscript. Literary source texts are not redistributed here.
