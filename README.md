# Golden Age Semantic Reconfiguration

Reproducible research repository for **Paper 1** on semantic-network reconfiguration across the Renaissance–Baroque transition in Spanish Golden Age poetry.

## Main notebook

The project uses a **single working notebook**:

`notebooks/paper1_analysis.ipynb`

Open it in Google Colab from GitHub and use it as the main analysis dashboard.

## Recommended workflow

1. Open `notebooks/paper1_analysis.ipynb` in Colab.
2. Run and develop the analysis there.
3. To preserve notebook changes, use **File → Save a copy in GitHub** and overwrite the same notebook on branch `main`.
4. Reusable scientific code will progressively be moved to `src/`; figures and tables will be stored under `results/`.

## Current milestone

**Sprint 1 — Corpus Audit + Temporal Reconstruction**

Before building semantic networks, the project will reconstruct poem-level temporal metadata and quantify the historical coverage of the corpus.
